============================================================
 Godot Racer — 玩家说明（Windows 版）
============================================================

一、这是什么
------------------------------------------------------------
一个用 Godot 4 做的 3D 赛车小游戏：5 个关卡，天气会真实影响抓地力，
每关有 1 台会避让的 AI 对手陪你跑。

本包是**免安装**的：解压到任意目录，双击 Godot-Racer.exe 就能玩。
不需要联网，不需要账号，游戏本身也不收集任何数据。

本说明里的信息对应当前这个构建；具体构建号、引擎版本、各文件哈希
见同目录的 BUILD-INFO.txt。


二、开始玩
------------------------------------------------------------
1. 把整个文件夹解压出来（不要只解压 exe 一个文件）。
2. 双击 Godot-Racer.exe。
3. 主菜单里选关卡 → 调极速 → 回车开始。

主菜单操作：
  ↑ / ↓      在关卡之间切换
  Enter      开始所选关卡
  ESC        弹出退出确认
  极速滑条   80 ~ 240 km/h（默认 180）
  AI 对手    可开可关；关掉后所有关卡都不生成对手
  帧率       60 / 120 FPS；物理计算固定 120 Hz


三、键位
------------------------------------------------------------
  W             油门
  S             刹车 / 倒车
  A / D         左 / 右转向
  空格          手刹
  R             复位（把车放回赛道；贴近赛道中心时会先扶正车身）
  V             切换视角（第一 / 第二 / 第三人称）
  M             显示 / 隐藏小地图
  鼠标右键拖动  环视四周
  ESC           比赛中打开暂停菜单；结算时返回选关

注意：键位是按**物理键位**绑定的，也就是说在 AZERTY / QWERTZ 键盘上
要按键盘同一个**位置**上的键（不是看字母）。例如 QWERTZ 键盘上"油门"
是物理 W 位（字母 Z 那一列）。


四、5 个关卡
------------------------------------------------------------
  1. 新兵训练营   简单    晴        建议极速 160 km/h
  2. 阳光竞速场   普通    晴        建议极速 180 km/h
  3. 雨夜街道     困难    雨        建议极速 200 km/h
  4. 荒漠遗迹     极难    沙尘      建议极速 220 km/h
  5. 极地挑战     地狱    雪        建议极速 240 km/h

天气不只是换颜色：雨、雪、沙尘会真实降低抓地力，刹车距离会变长。
每关各有 1 台 AI 对手，和你在起跑线并排发车（你起步它才起步）。


五、设置和进度存在哪儿？
------------------------------------------------------------
帧率和窗口尺寸保存在 user://settings.cfg，重开后会恢复；首次启动窗口
以 1280×720 为目标，按屏幕可用空间缩小并居中。关卡、极速、AI 开关
只在当次运行有效；本版不保存比赛进度。Windows 的用户数据目录通常为：

  %APPDATA%\Godot\app_userdata\Godot Racer\

（%APPDATA% 可以直接粘到资源管理器地址栏。）

运行日志（排查问题时用）在 Godot 的默认位置：

  %APPDATA%\Godot\app_userdata\Godot Racer\logs\godot.log

（这一路径取自 Godot 4 的默认日志设置；若没有文件，请检查同目录的 logs。）

想彻底重置游戏：直接删掉上面这个 app_userdata\Godot Racer 文件夹即可
（下次启动会重新生成设置；删除前可先备份 settings.cfg。）


六、已知限制（不是 bug，是这版就还没做）
------------------------------------------------------------
- 有引擎占位声和雨天环境声；背景音乐与其它音效尚未制作。
- AI 对手只做"沿着赛道跑 + 避让你和障碍"，不会主动超车、也不走最优线。
- 障碍布局是固定的（按关卡配置和固定种子生成），每局一样，没有随机化。
- 不支持手柄：所有操作都是键盘 + 鼠标。
- 没有游戏内全屏切换；窗口可以调整尺寸并会记住。
- 界面只有中文，没有多语言（本版没有接入翻译系统）。
- 第 4 关曾有自动驾驶卡住记录；修复后的历史三次三圈记录未再卡住。默认 60 FPS
  下的全量 20 项自动验收已通过，60/120 FPS 双档长时跑圈各 9 次也已通过。
  手动游玩时若卡住，按 R 复位。
- 第 5 关雪地 100 km/h 急刹的实测减速低于部分中速档，属于已测出的极端边界；
  这版请提早制动。两档 AI 跑圈均完成，但手动驾驶手感尚未实测。

下面这几条**不是功能没做**，而是本版**还没验证到位**，如实告知：
- 结算（跑完最后一圈后的完成页）只验证了**逻辑**，没有在导出包里实机走完一遍：
  重复完成不叠加面板、进入结算后驾驶输入已释放、三个出口（重新开始 / 返回选关 /
  退出游戏）、ESC 返回选关、取消后回到精确状态、重开后保留设置 —— 这些都有自动化
  断言覆盖；但「在你的电脑上跑到最后一圈、结算页真的弹出来并且点得动」
  **只能人手确认**。如果你跑满圈数却没出结算页，请按下面的 Q8 反馈。
- 音频的**客观部分**已有 37 项自动化断言覆盖（总线结构、雨声挂在 Ambient 总线、
  循环开关已开、暂停/恢复状态翻转、重复进入雨关不叠音、切到晴关后节点归零等）；
  但**主观听感**无法自动验收，以下六项需要你用耳朵判断：
  ① 雨声与引擎声的音量比例从未调过（三条总线都是 0 dB，引擎声在 SFX 上是 -6 dB，
     雨声在 Ambient 上是 0 dB）；
  ② 雨声是 204.55 秒的循环，只证明了循环开关是开的，接缝处有没有「咔哒」声只能听；
  ③ 引擎声是用代码实时合成的**占位音**（22050 Hz、0.5 秒缓冲），不是真实引擎采样，
     它和雨声叠在一起的听感未验证；
  ④ 暂停后恢复播放，已验证状态翻转正确、且确实是续播（不是从头开始）；但恢复
     瞬间会不会有爆音只能听；
  ⑤ 从雨天关卡切到晴天关卡，只验证了相关节点已归零，耳朵里有没有残留只能听；
  ⑥ 上面五条都是开发环境里得出的结论，**导出包里到底有没有真的出声、音量是否
     一致**，同样没有验证。觉得刺耳、太小声或听不见，请按下面的 Q8 反馈。
- 本版**没有在干净的 Windows 上验证过**：我们只在一台装着 Godot、显卡驱动齐全的
  开发机上跑过。全新系统「解压即玩」这条路径的首启表现（黑屏、显卡驱动、杀毒
  软件拦截等）**未覆盖**，遇到问题请看上面的 Q1。
- 极速滑条只在**当次运行**有效，重开游戏会回到默认（详见第五章与 Q5）。

运行环境要求：
- Windows 10 或更高版本（64 位）
- 显卡需要支持 Vulkan 1.0 或 Direct3D 12（游戏用的是 Forward+ 渲染管线）。
  较老的集成显卡、只支持 OpenGL 的环境可能启动失败。


七、常见问题（FAQ）
------------------------------------------------------------
Q1. 双击 Godot-Racer.exe 没反应，或者一闪就没了？
    → 先看 BUILD-INFO.txt 里的"打包形态"那一行怎么写：
        · 独立 PCK：exe 和同目录的 Godot-Racer.pck 必须一起在，少一个就
          起不来（最常见的就是只把 exe 拷出来了）。
        · 内嵌 PCK：资源封在 exe 里，只有 exe 一个文件，不存在这个问题。
    → 如果是黑屏/闪退，多半是显卡驱动或渲染后端问题：更新显卡驱动，
      或到"设置 → 显示 → 图形"里确认游戏能用独显。
    → 想看到具体报错：Win+R 输入 cmd 回车，然后把 exe 拖进命令行窗口
      回车运行，报错会留在窗口里；同时看第五章的 godot.log。

Q2. 提示缺少 DLL、或者要我装 Visual C++ 运行库？
    → **不需要安装 Microsoft Visual C++ 2015-2022 可再发行组件（x64）。**
      这一条已经**实测**，不再是推测：我们解析了 Godot-Racer.exe 的 PE 导入表，
      它一共引用 22 个 DLL，全部是 Windows 系统自带库（KERNEL32 / USER32 /
      GDI32 / dxgi / DWrite / WS2_32 / msvcrt / ntdll 等），**没有**引用
      MSVCP140.dll、VCRUNTIME140.dll、VCRUNTIME140_1.dll、UCRTBASE.dll 这类
      VC++ 运行库 —— 也就是说 MSVC 运行时是**静态链接**进 exe 的。
    → 如果你仍然遇到「缺少某个 DLL」的提示，那多半不是 VC++ 运行库，而是显卡
      驱动或系统组件的问题，请回到上面的 Q1 处理，并把报错原文附给我们。
    → 口径边界：上面是**本构建**（见 BUILD-INFO.txt 里的构建号）实测出来的结论。
      后续版本若更换了导出模板或构建配置，这条必须对新的 exe 重新实测一次，
      不能自动沿用到别的构建号上。

Q3. 杀毒软件 / Windows Defender 拦截了，是病毒吗？
    → 我们不能替你下结论，但可以给你核对的方法：
      ① 本程序**没有做代码签名**（构建配置里签名是关闭的），所以系统
         无法用签名校验来源，这类"新出现、未签名、体积较大的打包程序"
         比较容易触发启发式和信誉判定。
      ② 先核对哈希，再说别的。命令行里执行：
             certutil -hashfile Godot-Racer-<构建号>.zip SHA256
         把它和随包的 Godot-Racer-<构建号>.zip.sha256 文件里的值逐字符
         对比（大小写不敏感）。**如果对不上，那你拿到的就不是我们发出的
         包，不要运行，也不要放行。**
      ③ 如果哈希对得上但被拦截：先**不要直接放行**。请把拦截信息原样
         保留下来 —— 杀软名称与版本、提示原文（尽量截图）、被拦截的文件
         名和它的 SHA256。
      ④ 把样本和上面的信息提交给杀软厂商的"误报上报"通道复核；复核确认
         为误报后，再决定要不要加白名单。
    → 我们不会建议你关闭防护，也**不会**把所有拦截都当成误报：哈希不一致
      就说明包被动过，那种情况请直接丢弃。

Q4. 玩起来卡顿 / 掉帧？
    → 关掉其它吃显卡的程序；笔记本请插电源（省电模式会限制性能）；
      更新显卡驱动。本版没有画面质量选项，暂时只能靠这些外部手段。

Q5. 我调了极速、选了关卡，重开游戏又变回去了？
    → 这两项本版只在当次运行有效；帧率和窗口尺寸会保存。

Q6. 为什么没有背景音乐？
    → 本版只有引擎占位声和雨天环境声，没有背景音乐。

Q7. 怎么卸载？
    → 免安装：直接删掉这个文件夹。想连用户数据一起清掉，就再删
      %APPDATA%\Godot\app_userdata\Godot Racer（见第五章）。

Q8. 怎么反馈问题？
    → 反馈时请带上：BUILD-INFO.txt 里的**提交号 / 构建时间**、
      你做了什么、期望什么、实际什么、能否复现。
      如果有 logs\godot.log 也一起附上，定位会快很多。


八、这个文件夹里的文件是干什么的
------------------------------------------------------------
  Godot-Racer.exe     游戏主程序
  Godot-Racer.pck     游戏资源包（贴图、模型、脚本等）。只有"独立 PCK"形态
                      的构建才有这个文件，且必须和 exe 放同一目录；
                      "内嵌 PCK"形态没有它，资源已经封在 exe 里。
                      到底是哪种，看 BUILD-INFO.txt 的「打包形态」。
  BUILD-INFO.txt      构建信息：提交号、版本、构建时间、哈希
  README-玩家版.txt   就是本文件
  LICENSE             本游戏自有代码的授权（MIT）
  THIRD_PARTY_NOTICES.md      第三方素材来源与许可边界
  THIRD-PARTY-LICENSES.md     随包分发的第三方许可（Godot 引擎、音效等）

如果同目录还有 .dll 文件，它们是运行必需的，不要单独删。
