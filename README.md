# Godot Racer｜从第一圈开始的赛车策划作品

> 本目录是2026-10-27五关固定升级试玩候选，交付与未验收边界见[本轮报告](plan/five-fixed-delivery-20261027.md)。

2026-10-27最新源码：五关高红围挡已默认隐藏，原位空气墙及路宽保留；所有关卡都有红白路缘，并新增约24米间隔、0.72米高的低矮反光桩。雨夜路灯左右对称朝向道路，车辆附近使用4盏真实聚光灯，并提高基础环境光，让路面和边界可辨认。

L2已接入真实坡道及3×3受约束随机组合的源码试验入口，其他四关尚未推广。开发运行时添加 `-- --race-variants` 再从菜单选择第二关；同局重试保留组合，返回菜单再开重抽。当前是三种高度剖面×三种固定种子路障布局，平面路线固定。用户要求整体交付节点再统一导出；现有EXE/ZIP均为早期版本，不包含本轮全部源码修改。最新验证及未过项见[本轮续作与回归](plan/L2-validation-resume-b-20261027.md)。

Godot Racer 是一款包含 **5 个关卡**的单机 3D 赛车原型：先在晴天宽路熟悉驾驶，再面对雨夜、沙尘、雪地和障碍。你可以开启 AI 竞速，也可以关闭对手练习路线。项目重点展示规则设计、关卡难度递进、界面取舍，以及根据试玩反馈进行迭代的过程。

## 第一次玩，先做这四步

1. 打开首页，点击“开始游戏”进入选关。
2. 单击赛道查看天气、圈数、障碍和推荐极速；第一次建议从“新兵训练营”开始，并关闭 AI 练习。
3. 双击赛道，或点击“开始比赛”。等待 3、2、1 和“出发！”；此时开始驾驶与计时。
4. 按顺序通过检查点并完成目标圈数，在结算页查看成绩，再选择重试或返回首页。

首页的“设置”可切换 AI、60/120 FPS 和背景音乐；选关页可调整最高速度。先用推荐值熟悉路线，再尝试自己的调校。

| 操作 | 按键 |
|---|---|
| 加速 / 刹车与倒车 | W / S |
| 左右转向 | A / D |
| 手刹 | 空格 |
| 车辆复位 | R |
| 切换视角 | V |
| 拖动环视 | 鼠标右键 |
| 暂停、返回或退出确认 | ESC |

游玩界面已取消小地图，M 键不再绑定功能。圈数、速度、单圈与总时间继续保留。首页展车支持左键拖动；鼠标命中汽车时暂停自转，放在台面或 Logo 上则继续展示。

菜单使用霓虹光标；进入关卡装配、倒计时和驾驶后自动隐藏。暂停、退出确认、结算或返回首页时恢复，继续比赛后再次隐藏；右键环视仍按原方式操作。

## 一局比赛围绕哪些决策展开

玩家需要在直道加速、入弯前减速、为障碍留出路线，并判断是否应该使用复位。天气和路宽让相同的油门、刹车与转向产生不同风险；最高速度也是可调整的选择，而不是必须始终踩满的目标。

开启 AI 时，玩家与对手在倒计时结束后同步获得驾驶许可；关闭 AI 时进入练习，不把单人完赛包装成击败对手。成绩区展示总时间、末圈和最快圈，帮助玩家比较下一次尝试。逆行和复位反馈用于解释错误，计圈按实际检查点与压线规则判断。

## 五关如何逐步增加挑战

以下数值来自当前关卡配置，表示设计条件；推荐极速并非实测最优速度。

| 关卡 | 条件 | 圈数 | 希望玩家练习的决策 |
|---|---|---:|---|
| 新兵训练营 | 18 m 宽路、Brands Hatch Indy结构、无障碍 | 2 | 建立转向与刹车的基本节奏，理解压线和计圈 |
| 阳光竞速场 | 16 m 宽路、Snetterton 200结构、固定模式无障碍 | 2 | 在长直道加速，并提前为下一弯准备 |
| 雨夜街道 | 15 m 路宽、Oulton Park Fosters结构、抓地倍率0.70、3个静态障碍 | 2 | 提前减速，给低抓地力和绕障留余量 |
| 荒漠遗迹 | 14 m 路宽、Big Willow结构、6个固定路障 | 2 | 连续规划路线，避免只对眼前障碍做反应 |
| 极地挑战 | 13 m 路宽、Hungaroring结构、抓地倍率0.50、4个静态障碍 | 2 | 在更紧凑的路线中平衡速度、制动和安全距离 |

五关平面路线均已改为不同真实赛道结构的游戏化改编，非测绘复刻。默认固定模式无坡度、动态障碍为0；L2随机试验使用最高6/10/16m的三种高度剖面与三种两路障布局。关卡条件以 `godot-racer/data/levels/*.tres` 和试验目录 `godot-racer/data/variants/l2-catalog.json` 为准，整体平衡仍需要真人试玩支持。

## 这个项目展示怎样的策划过程

| 体验目标或反馈 | 落到规则与界面的取舍 | 如何核对 |
|---|---|---|
| 让玩家先理解入口和赛事条件 | 首页与选关分层；单击查看，双击或按钮确认开赛 | 真实控件与页面测试，保留真人体验反馈 |
| 让展车可以看、可以操作 | 车与展台分离拾取；只有汽车响应悬停和拖拽 | 真实3D射线、轮廓间隙和状态切换用例 |
| 让入场有节奏 | 先升起空展台，再渐显并旋转汽车；重进快速恢复 | 时间线断言、实际截图与自动录像 |
| 首页左下文字显得拥挤 | 说明文字下移22个设计像素，音乐开关和输入顺序保留 | 1366×705实测留白由8px增至30px，三尺寸复核 |
| 用户决定取消游玩小地图 | 取消地图世界和HUD面板，移除M动作及帮助说明 | 真实倒计时后游玩检查，验证M和旧CLI均不能恢复它 |

用户负责体验目标、规则取舍、审核与真实试玩反馈；AI辅助代码、资源工具、文档和自动化检查。这里展示可追溯的需求、实现与验证，不虚构玩家研究、商业数据或个人手写经历。当前具体策划记录见[设计说明](godot-racer/docs/portfolio-design.md)、[首页展台方案](plan/Godot_Racer_首页展台交互与入场动画_实施计划_2026-10-23.md)与[首页依赖及迭代记录](plan/showcase-完整首页依赖发布-20261025.md)。

## 当前状态与限制

源码已有五关、键盘驾驶、可关闭的 AI、天气、障碍、暂停、结算和菜单音乐。最新专项结果如下；每项绑定自己的源码和原始记录，不能合并成全项目验收。

| 本轮检查 | 实际结果 |
|---|---|
| 五关边界、红白路缘、桩体位置及无新增碰撞 | 真实渲染25/0；改前后五关路面/空气墙碰撞哈希及路宽一致 |
| 五关装配、发车及返回菜单 | 16/0，有真实截图 |
| 最终四灯雨夜照明、方向、镜像、随车更新与释放 | Compatibility 9/0，720p/1080p截图已检查 |
| L1贴墙原专项 | 12/12；修正验收包围盒投影误差，未改物理与阈值 |
| 完整lint、生产脚本解析、两道文档闸门 | 通过；4个BAT仅将行尾改为CRLF，编码和命令内容不变 |
| 雨夜天气步频 | 最终默认Compatibility约119.8Hz，通过原118Hz门槛；四灯Forward+约116.5Hz，未通过 |
| 雪地天气步频 | 当前Compatibility约116.2Hz，未通过；旧固定版同机约120Hz通过，待定位差异 |

L2九组合AI两圈的固定步长检查已通过；玩家组合0/4的60/120目标档四次比赛通过（早于本轮最终视觉源码）。最终源码的AI双档18次矩阵及剩余玩家组合尚未完成，不能据此宣称持续60/120FPS。历史性能与机器检查均绑定各自版本，详见[测试说明](godot-racer/docs/testing.md)。

用户已反馈首页整体“感觉还行”，并提出文字间距与小地图取舍。最新修改仍需要用户复看；自动截图和录像不能代替真人验收。主观驾驶手感、音乐听感、导出包完整通关和干净 Windows 首启尚未完成本轮验证。编辑器导入/退出的已知诊断和旧红日志保留在相应记录中，不据局部通过宣称整个游戏全绿。

尚未提供手柄、多人和完整商业化内容。五关固定版已在本地导出Windows EXE/ZIP并完成同机工程外装配检查；L2随机试验的导出与验证状态单列在续作报告。均未公开上传，不代表真人或外机验收通过。

## 开发者如何运行和复核

使用 Godot 4.4.1 标准 Windows 版打开 `godot-racer/project.godot`，或在仓库根目录执行：

```powershell
& 'E:\godot\Godot_v4.4.1-stable_win64.exe' --path .\godot-racer --rendering-method gl_compatibility
```

L2随机试验入口：

```powershell
& 'E:\godot\Godot_v4.4.1-stable_win64.exe' --path .\godot-racer --rendering-method gl_compatibility -- --race-variants
```

Forward+可通过 `--rendering-method forward_plus` 手动选择，其当前雨夜步频失败仍待排查。目标渲染档位和固定120Hz物理配置不等于已持续达到目标性能。

相关验证入口如下，标签须换成新的名称以保留历史证据：

```powershell
python godot-racer/tests/run-minimap-removed.py NEW_TAG --graphics
python godot-racer/tests/run-showcase-delivery.py matrix NEW_LAYOUT_TAG
pwsh -File .\04-Godot启动器\check-readme.ps1
pwsh -File .\04-Godot启动器\check-docs.ps1
```

底层诊断入口按职责保留：场地与恢复 `enclosure`、`layout`、`reset`、`oob`、`escape`、`resetkey`、`wallslide`、`flip`；对手与避障 `opponents`、`avoid`、`obstacles`、`aistart`、`aidiag`；驾驶与流程 `phys`、`weather`、`friction`、`steerbench`、`brakebench`、`stress`、`stuck`、`lap`、`reverse`、`pause`；界面移除回归 `minimap`。例如由启动器 `run-check.ps1 -Check minimap` 检查小地图和M绑定均不存在；这是兼容的检查名称，不是重新启用功能的入口。
