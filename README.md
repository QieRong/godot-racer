# Godot Racer

一款低多边形 3D 赛车游戏。驾驶红色赛车，在五条赛道上比较圈速、挑战 AI，或和朋友共用一台电脑竞速。

**Windows PC · 五条赛道 · 单人两圈 / 无限练习 · 本地双人分屏**

![Godot Racer 4.7.2 开发候选的首页与红色赛车](screenshots/20261104/home.png)

## 玩法

| 模式 | 开发候选的比赛规则 |
|---|---|
| 单人竞速 | 选任意赛道，完成两圈并记录整场成绩。AI 可在设置中开启或关闭。 |
| 无限练习 | 持续跑圈、熟悉路线，按赛道保留最佳单圈。 |
| 本地双人 | 同一台电脑左右分屏，共用键盘。入场后直接倒计时，先完赛的赛车立即停住，另一位玩家可继续比赛。双人赛有独立结算。 |

![三个玩法入口](screenshots/20261104/mode-selection.png)

从首页选择「开始游戏」，再选玩法和赛道。赛道选择页可查看个人纪录并调整速度上限。单人普通比赛按赛道记录完成进度。个人最佳幽灵回放有效的驾驶轨迹，近距离冲线时可播放终点摄影。

![五条赛道与个人纪录面板](screenshots/20261104/track-selection.png)

## 键盘操作

以下是开发候选的默认键位。进入首页「操作帮助」，选择单人或本地双人标签，点击漂移键即可改键。单人与 P1 共用一套漂移键，P2 可单独设置。冲突的键位会提示原因，保存的键位在重启后恢复。

| 操作 | 单人 / P1 | P2 |
|---|---|---|
| 加速 / 制动与倒车 | W / S | ↑ / ↓ |
| 转向 | A / D | ← / → |
| 手刹 | 空格 | 右 Ctrl |
| 漂移（按住） | 左 Shift | 主键盘 / |
| 后视（按住） | C | 右 Shift |
| 切换视角 | V | Enter |
| 车辆复位 | R | Backspace |
| 暂停 | Esc | Esc（暂停双方） |

![操作帮助的双人键位与漂移改键入口](screenshots/20261104/split-controls.png)

过弯时按住漂移键进入侧滑，适时反打方向可修正角度。复位会把车送回附近安全位置。分屏中，逆向提示显示在对应玩家的画面内，暂停菜单可以重看双方键位。

![阳光竞速场分屏 HUD，左侧画面出现逆向提示](screenshots/20261104/split-race.png)

## 语言与声音

「设置」可切换简体中文、繁体中文、English、Русский、日本語、한국어，也可跟随系统。设置随游戏保存。六种语言覆盖首页、玩法、选关、操作帮助和主要比赛界面，仍在补查各比赛状态和窄窗口布局。

「设置 → 背景音乐」统一控制菜单和比赛 BGM。分屏中两台赛车都有引擎反馈。比赛音乐下调了音量，碰撞音按冲击强度变化，隐藏检查点已静音。

## 从公开源码运行

1. 克隆 [QieRong/godot-racer](https://github.com/QieRong/godot-racer)。
2. 使用 **Godot 4.4.1 标准版**导入 `godot-racer/project.godot`。
3. 等待资源导入完成，运行主场景。两套工程均采用 **Compatibility、Jolt、120 Hz 物理更新**。

```powershell
git clone https://github.com/QieRong/godot-racer.git
cd godot-racer
& 'C:\Tools\Godot\godot.exe' --path .\godot-racer
```

将示例中的可执行文件替换为本机的 Godot 4.4.1 路径。使用本地 4.7.2 迁移候选时，从迁移目录的 `04-Godot启动器/运行游戏.bat` 启动，或用 4.7.2 打开候选工程的 `project.godot`。
