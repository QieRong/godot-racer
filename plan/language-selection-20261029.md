# 六语言方案 · 2026-10-29 · 仅规划，未实施/未实测

玩家目标：在首页直接识别和切换语言，不影响开始比赛、展车拖拽或已有设置。当前用户要求先规划；不把规划标为功能已实现。

## 布局与交互

- 放在旋转赛车展示区右上角，作为独立UI控件，不随3D赛车旋转。相对既有1366×705基准，展示区为(460,82,874,510)；建议按钮Rect2(1134,94,176,40)，距展示区右边24px、上边12px。采用与首页相同的Stage缩放；720p和1080p逐项验证，不固定在物理屏幕坐标。
- 收起时显示“语言 · 简体中文 ▾”；切换后显示对应语言自身名称。使用文字/语言图标，不用国旗代表语言。当前页保留一个语言入口。
- 展开列表：简体中文 / 繁體中文 / English / 日本語 / Русский / 한국어；当前项带勾选。按钮最小40px高，文字18px，列表支持键盘↑↓、Enter确定、ESC收起；Tab进入/离开；点击列表外收起并恢复触发按钮焦点。
- 列表打开时阻止底部展车接收同一鼠标点击/拖拽；关闭时恢复。ESC先关闭语言列表，后续ESC才触发首页退出确认，不能一次执行两项。
- 选择后即时切换当前页面和已有可见弹层，保留焦点、选关、AI/音乐/帧率选择。按钮不靠文字长度改变锚点。长俄语控件优先留宽与换行，不压成难读小字。

## 资源、状态与边界

| 显示名 | locale |
|---|---|
| 简体中文 | zh_CN |
| 繁體中文 | zh_TW |
| English | en |
| 日本語 | ja |
| Русский | ru |
| 한국어 | ko |

首轮默认简体中文，保存有效选择到现有ConfigFile的独立ui/locale键；读取缺失或无效值时回退zh_CN，不覆盖其他设置键。设置写入失败要保留本次界面选择并明确提示“未保存”，不能声称已持久化。locale仅影响显示，不改AI/物理/随机种子/关卡资源字段。

采用Godot内置TranslationServer与本地翻译资源，使用稳定键（如HOME_START、HELP_REAR、HUD_LAP），不新增联网翻译依赖。动态数字/键位/关卡条件使用占位符；操作帮助继续读取InputMap。关卡display_name保留当前数据标识，仅在展示层映射翻译，避免现有中文字符串判断改变玩法。

翻译覆盖：首页、选关及关卡说明、设置/帮助、倒计时、HUD、复位/逆行反馈、暂停、结算、确认弹窗和面向玩家的装配错误；开发日志/代码注释不属本轮翻译范围。繁体需人工检查用语；日/俄/韩均先标机器草稿待校对，不声称母语质量已验收。缺译显示简体回退，不显示裸key或空白。

字体需选择许可可追溯、可随包分发的CJK/拉丁/西里尔组合；先核对项目已有字体与体积，缺字再新增。不能依赖开发机已安装字体就声称其他Windows电脑无方框。不能凭规划确认现有字体覆盖日韩。

## 分批实施与验收

1. 国际化基础与首页按钮：六locale注册、保存/恢复/非法值回退、首页/帮助切换，保留所有现有输入。先红后绿，真实菜单截图核对。
2. 比赛全流程文字：选关→倒计时→HUD→暂停→结算→再玩，所有动态占位符匹配；语言切换不重开比赛或重置成绩。
3. 翻译/字体复核：六语言×720p/1080p，键鼠操作、焦点、长文本、缺译/缺字/设置不可写、重启记忆；真人逐语言认可单列U状态。不自动扩成五关90场物理矩阵。

候选影响：scripts/homepage.gd、ui_theme.gd、menu.gd、menu_overlay.gd、独立locale服务、对应UI脚本和translations资源、专项测试。GameState仅接入已有配置保存点，避免堆大文件；所有新增/修改GD≤1000行。当前优先级仍是阴影修复、去除重复音乐入口、四关随机AI与已知渲染/音频问题；语言实施另立小工单。
