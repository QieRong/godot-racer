# UI-20261020 首页、倒计时、结算规格与专项判据

状态：用户已确认产品取舍；实施与自测结果见同目录 ui-selftest-20261020.md；正式 T/U 待本机复跑与真人确认。

基线：4135f86；1366×705；Godot 4.4.1。现有冻结带、导入文件、未跟踪文档/工具不属于本工单。

## 共用规则与实现边界

- 纯脚本构建，不修改场景、物理、AI、几何、关卡配置、GameState、main 发车回调、旧测试或验收阈值。
- 固定设计坐标 1366×705，居中等比适配：scale=min(视口宽/1366,视口高/705)；1920×1080 时设计区为 1920×990.922，居中上下各 44.539。背景覆盖整个视口。
- 令牌 ui_theme.gd：背景 #0B0D11；面板 #14171C；白字 #F3F6FA；次文字 #B8C2D1；边框 #364152；警示 #F1C477；圆角 14；字号 15/18/19/24/32/40。倒计时数字专用 96，HUD 保留现有 26/46。
- 强调色由真实配置 weather_type/is_night 选择：clear #7FB3E8；rain+night #6E86C8；sand #E0B368；snow #A8C4DC；未知天气回晴天色。底色不随主题变化。
- 不引入资源、字体文件、框架或依赖；使用内置控件、主题与系统字体回退。辅助模块无 class_name，由 preload 消费，数据/回调经 setup 注入。
- 动效不引入 await；不参与流程条件；Tween 独立运行；每个按钮从出现第一帧即可操作。菜单已有 CLI 截图/自动开始辅助协程保留，禁止新增 UI 协程。
- 不展示历史纪录、分段、名次变化。当前数据没有超时原因，不设 UI 自造的超时钟，不将缺失数据误称超时。

### 交互

- 默认焦点：当前选中关卡；没有关卡时为设置。鼠标点击卡片直接进入；悬停仅更新选关信息，不抢键盘焦点。开始按钮进入当前选择。
- 卡片 focus_neighbor_top/bottom 仅在关卡间循环；Enter 开赛。Tab 顺序：关卡1…N→首页AI开关→极速→开始→设置→帮助→退出→关卡1，shift+Tab 反向。所有 next/previous 显式设置。
- 2026-10-20用户截图反馈：首页需要直接可见的AI开关；因此信息板增加快捷开关。设置弹层里的同一开关保留，两者共享GameState.ai_enabled，不引入第二套状态。
- 设置弹层焦点：AI→FPS→返回，top/bottom/next/previous 都循环；帮助只有返回。弹层打开后禁用底层 focus_mode；ESC先关闭弹层并恢复原触发按钮；首页ESC走现有退出确认。EXIT_CONFIRM 期间首页不响应ESC；取消后恢复退出前焦点。
- 卡片滑入：x偏移24→0、透明0→1，用Tween 0.24秒，依次延迟70ms。位移发生在卡片内部视觉承载层，不改变其焦点与点击区域。没有焦点阻塞计时器。

键鼠无焦点。ESC沿既有pause_menu→退出确认→取消回COUNTDOWN；本页不吞ESC，不释放按住的油门，不新建相位。
