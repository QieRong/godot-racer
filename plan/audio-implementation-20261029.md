# 玩家引擎三视角混音实施计划

**目标**：实现用户已批准的本车引擎距离补偿、弱声像和可辨怠速；第一人称保留车头外部质感。规格为`audio-perspectives-20261029.md`及2026-10-29本轮用户确认。

**架构**：`engine_audio.gd.setup(car)`只配置注入的玩家音源；`vehicle.gd`继续独占最终`volume_db`和RPM/负载音高，不由相机争写。保留现有3D声源与总线，不新增监听器、素材、依赖或雨声动态避让。

**技术栈和约束**：Godot 4.4.1 / Compatibility / 120Hz物理。仅一个音频工单，不改物理/AI/核心几何、不重冻、不启动90场、不导出EXE、不上传私有资产和原始日志。常规修改GD≤1000行。

## 基线

完整候选基于公开593cd08；本地隔离平直场使用真实车、相机、音源和油门输入，WASAPI/48kHz。12段（3视角×怠速/加速/约60km/h巡航/收油）共36分轨，退出0、无丢帧和源码漂移。

巡航引擎RMS：车头-16.05、近跟随-13.73、远跟随-20.29dBFS，跨度6.56dB；各段雨声约-25dBFS。远视角引擎300–3000Hz比雨声低1.17dB。怠速稳定后末500ms引擎约-64至-71dBFS。软件总线测量不是LUFS或设备实听。

## 重点检查

1. 暂停/恢复保留单一雨声循环和引擎；缺音源安全退出。
2. V/C/环视不改变RPM，不插入封闭座舱滤波；弱声像仍要测左右差和切换。
3. 怠速、全油门、收油保留渐变；冻结/复位不产生新的驾驶规则。
4. 重试与返回菜单不叠播；等待AudioServer回执失效，不用固定sleep掩盖泄漏。
5. 基线与候选源快照分开保存；不把平直场结果说成雨夜赛道或真人验收。

回退只还原本工单两个生产脚本及对应文档，不动用户导入元数据、模型或其他工作树。
