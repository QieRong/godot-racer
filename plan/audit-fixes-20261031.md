# 2026-10-31 独立游戏方向首批修正

## 行为变更

- 玩家 S 动作在前进时先施加车轮制动，接近停车后进入倒车；倒车时 W 先制动。模拟量按力度制动，保留空格制动、发动机制动和原倒车驱动力上限。生产代码不直接修改速度来刹停。
- 普通带 AI 比赛不再等待 60 帧预热与 120 帧的无人读取基线采样；删除该专用状态和包装函数，保留诊断实际使用的性能采样器及检查入口。
- MCP 自动加载改走项目自有的可选开发入口：仅编辑器程序加载插件，发行模板不创建桥接；插件缺失时正常启动。导出配置排除 addons；已有本地插件补丁工具增加重新启用插件时保护该入口的补丁，重装插件后需重新运行工具。
- 两份 AGENTS 同步为长期独立游戏 v3.0，明确默认 Compatibility、Forward+ 独立验证，以及未经本轮明确授权不得提交推送。移除 UI 源码检查中的过时 1000 行硬断言，保留其余检查。
