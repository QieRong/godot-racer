# L4 候选代码自审（2026-10-15）

意图：修正 AI 轮舵角的几何含义，并让选道/排队覆盖实测跟踪偏差，不改变通过判据。

## 已核对

- 转向角继续沿用旧符号，真实轴距来自 _measure_wheel_base；横向加速度来自已按抓地缩放的上限。
- 转向权限、roll guard、move_toward 响应速率、轮胎参数、自救和 L5 probe 制动均保留。
- 曲率只实现于 RacingLine.pursuit_steering。占用只经 obstacle_field 原 lane_blocked/_occupies。
- _tracking_band 为偏差带唯一计算点；选道与无解后的排队查询使用同一带，避免一边发现受阻、另一边又解除等待。
- 障碍模块两个 API 均用可选尾参数，零偏差默认值保留既有调用；无障碍列表继续走旧返回路径。
- 候选验证覆盖目标与预测偏差路径之间全部横向位置，并检查原道路边界；未扩大路宽或移动障碍。
- 测试执行真实 AI 入口与真实障碍模块，有执行计数、失败计数和非零退出；两处根因均保留红灯证据。
- 单个新文件远低于 1000 行；AI 1686 行属于 AGENTS 已登记的历史超限修复性增量，未做无关重构。
- 无新增依赖，无密钥/网络接入，main.gd、车辆脚本、关卡数据及验收脚本未改。

## 实测限定

这是一份自审，不冒称独立评审。完整专项仍以对应进度日志的最终 DONE / EXIT 与判定行为为准。
第一版仅修曲率造成 L5 新卡点，已按失败记录；第二版必须重做两关冷启动与回归。
偏差带使用本帧实测误差，不等于对任意未来动态障碍相位的保证；不扩大已测范围。
玩家自动驾驶仍是另一条控制链，AI 的通过不能替代 lap L4 的完整三跑。
