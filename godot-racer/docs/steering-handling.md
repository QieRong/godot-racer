# 玩家转向响应与抗侧倾辅助（2026-10-29）

用户反馈：A/D在高速过弯发硬，要求兼顾低速并依据五关真实赛道调整。单纯加快转向在部分地图的连续反打中触发碰墙翻滚，原45°门槛未放宽；失败实验保留。用户随后明确批准隔离验证物理抗侧倾辅助。

## 采用的规则

玩家仍用InputMap的A/D动作，在物理帧读取输入。最大转角继续由原随速曲线、现有横向加速度预算及当前关卡抓地力共同约束；24个速度/抓地组合的最大转角与旧版逐项完全一致。低/高速稳定接地时转向建立速率6、回中/反打速率8；缺轮接地时回到原4的响应，避免在落地时骤变。

抗侧倾只通过apply_torque施加有硬上限的滚转力矩。目标法线复用当局最终赛道surface_frame，阻尼只读取滚转轴的角速度；不直接改线速度、角速度或姿态，不改车辆质量、悬挂、轮胎摩擦和AI。少于两轮接地、离路高度差超过0.9m、相对路面倾斜超过60°时不施力，完整腾空与已侧立的R/自动扶正仍由原系统处理。该辅助是街机稳定性设计，不宣称真实汽车仿真。

## 行业参考及适配

- [Unity官方WheelCollider车辆教程](https://docs.unity.com/en-us/engine/6000.7/manual/physics-section/physics-overview/collision-section/collider-shapes/wheel-colliders/wheel-collider-tutorial)：随车速缩小转角范围。本项目保留既有曲线及湿滑路面预算，不照搬Unity示例数值。
- [Epic官方VehicleInputRateConfig](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/VehicleInputRateConfig?application_version=5.6)：转向输入的增长/回落速率分别配置。本项目采用独立建立/回中速率，数值来自本车对照测试。
- [Epic官方目标姿态控制配置](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/VehicleTargetRotationControlConfig?application_version=5.4)：提供滚转回中、刚度、阻尼和上限等独立控制量。本项目只实现受接地状态和真实路面约束的滚转力矩，没有引入引擎或开源依赖。
- [Godot 4.4 VehicleBody3D说明](https://docs.godotengine.org/en/4.4/classes/class_vehiclebody3d.html)：车辆用steering/力控制，不直接改位姿；官方同时说明该类有已知局限。本轮保持现有VehicleBody3D架构，没有更换物理系统。

借鉴的是公开设计与接口思想，模块为本项目实现，没有复制第三方源文件或引入新依赖；不将其他引擎或游戏的成熟度当成本项目验收。
