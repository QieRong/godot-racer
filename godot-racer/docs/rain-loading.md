# 雨夜首次装配优化（2026-10-29，真人待验）

完整本地候选在920MX、Godot 4.4.1 Compatibility下，冷缓存进入雨夜比赛时，首批渲染帧及四级方向阴影拖慢装配。旧四级方案两次未通过既有30秒进入比赛门，失败记录保留。相同素材、灯光和完整AI的暖着色器缓存对照约14.36秒进入比赛，表明首次编译与绘制开销是重要因素；不能据此认定装配流程死锁。

仅雨夜主光改为两级级联，晴天和雪地仍四级。保持单一主方向光、150m阴影距离、级联混合、0.3阴影透明度和柔化2；车辆、树木和建筑仍投影。两级的远处阴影细节存在取舍，不能宣称画质完全相同。

这一取舍依据[Godot 4.4 DirectionalLight3D官方说明](https://docs.godotengine.org/en/4.4/classes/class_directionallight3d.html)：两级是性能与质量的折中，四级成本更高。本轮没有删模型、减少九间便利店、关闭全场阴影或修改30秒门。

两次两级冷缓存诊断约27.84/29.21秒进入比赛；正式配置不带诊断开关、不复用测试着色器缓存的复核为29.115秒。同机相同起跑阶段的绘制约1842→1200。既有真实渲染生命周期的首次装配、重试、新组合、返回菜单均通过；阴影专项8/0，并检查起点/中途/重访及轻微机位变化截图。诊断换位不等于真人第二圈验收。

数据来自含私有美术的完整本地候选；公开副本可选模型缺失时的回退不能替代该渲染验证。本机结果不代表持续120FPS、所有驱动或外机冷启动保证，30秒边界仍需关注。根证书读取错误及历史Forward+退出问题保留；用户需从统一运行游戏.bat重启，确认雨夜阴影风格和实际开赛等待。
