
# agents.md —— 赛车游戏项目 AI 代理开发准则

欢迎接手本项目（Godot 赛车游戏）。作为本项目的 AI 开发代理，你在执行任何任务前，必须严格遵守以下规则。这不是建议，这是必须执行的开发契约。

## 🚨 一、最高安全红线（违反将导致严重后果）

1. **API 密钥零泄露**：
   - 绝不允许在代码、注释、日志输出、报错信息中明文打印完整的 `sk-or-v1-` 密钥。
   - 如果必须输出，只能打印前 6 位加 `***`（例如 `sk-or-v1-62b***`）。
   - 密钥必须通过环境变量 `OPENROUTER_API_KEY` 或工程根目录的 `openrouter.local.cfg` 读取。禁止硬编码。
2. **版本控制防卫**：
   - 每次提交代码前，必须自动运行 `git status`，确保 `openrouter.local.cfg` 处于 Untracked 状态且被 `.gitignore` 忽略。一旦发现有被提交的风险，立刻停止提交并向我报警。
3. **代理隔离**：
   - Clash Verge 的代理（`http://127.0.0.1:7897`）**仅允许**用于 AI 测试模块。
   - 严格禁止开启系统代理或 TUN 模式，防止本地服务（如 DSH）因梯子断线而不可用。

## 🛠️ 二、核心工程规范

1. **配置与数据驱动**：
   - 严禁在代码中硬编码关卡参数（如半径、路宽、圈数）。
   - 关卡数据必须使用 `LevelConfig.gd` 结合 `.tres` 资源文件。新增关卡只需新增 `.tres` 文件，不得复制场景。
2. **性能红线**：
   - 生成护栏时，必须合并 `StaticBody3D` 物理节点，禁止产生成百上千个独立节点导致物理帧卡顿。
   - 右上角小地图（SubViewport）必须使用 `cull_mask` 屏蔽树木、草丛等非必要渲染物，并且相机固定包住全图，不要每帧跟随车辆移动。
3. **物理与操控**：
   - 墙面必须设置低摩擦材质（`physics_material` 摩擦系数 0.05），防止车辆浅角度切入时被“咬住”。
   - 必须保留“楔入救援”逻辑（检测给油+低速+贴墙，沿垂直墙方向位移 0.8m）。
   - R 键复位：离中心线 < 3米时只扶正车身，超出或翻车才传送回最后一个检查点，防止误触打断驾驶。

## 🤖 三、AI 测试模块规范（不写死数据）

1. **AI 角色定义**：
   - AI 不逐帧开车（免费 API 延迟高），仅用于生成测试用例参数（JSON）和归因日志。
   - 主力测试必须放在本地确定性测试（`--check=stress`）上。
2. **API 交互健壮性**：
   - 使用 Godot 的 `HTTPRequest` 节点，必须设置 `timeout`（建议 1.0 秒）。
   - 提示词必须强制要求返回 JSON，例如：`{"throttle": 0.5, "brake": 0.0, "steering": -0.2}`。
   - 遇到 429（限流）或 401（密钥错误）：必须立刻打印详细错误，并自动降级为“本地确定性测试”模式，绝不允许卡住游戏运行。
   - 默认模型：`nvidia/nemotron-3-ultra-550b-a55b:free`。如果响应过慢，请切换为轻量级模型（如 `meta-llama/llama-3.1-8b-instruct:free`）。

## 🧪 四、验证与自检（先查根因，再写代码）

在修改任何核心逻辑后，必须按顺序执行以下验证命令，并确保全部通过：

1. `--check=enclosure`：沿中心线每 0.1m 发射射线，必须 100% 命中围墙（0 缺口）。
2. `--check=wallslide`：以 5°/10°/20° 角度怼墙，全油门 3 秒，必须不卡死。
3. `--check=stress`：3000 帧鲁棒驾驶，卡死事件必须为 0。
4. `--check=lap`：自动驾驶完整跑圈，无异常。

**排查 Bug 时**，禁止靠读代码猜测。必须使用射线探针、打印物理状态等“硬数据”定位根因，并在汇报时附带证据。

## 🗣️ 五、沟通与汇报协议

1. **诚实原则**：如果没能复现用户描述的问题，必须诚实说明“未能复现”，并附上已有的硬数据，绝不准编造证据。
2. **计划先行**：在动手写代码前，必须先提交“实现规范”和“验收标准”，等待我批准后再动笔。
3. **测试报告**：每次提交代码时，必须附带对应的测试运行日志摘要，证明没有引发回归缺陷。

## 📁 六、目录结构约定

- `scenes/`：场景文件（`menu.tscn`, `game.tscn` 等）
- `scripts/`：GDScript 脚本（`vehicle.gd`, `track_generator.gd`, `hud.gd` 等）
- `data/levels/`：关卡配置文件（`.tres`）
- `assets/textures/`：AI 生图素材（由开发期 Agnes 生成，打包进游戏，禁止运行时实时生成）
- `tools/`：Python 测试脚本与生成器（如 `test_generator.py`）
