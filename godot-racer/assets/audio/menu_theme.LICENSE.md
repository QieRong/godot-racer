# menu_theme.ogg 来源与生成说明

- 本项目用户于2026-10-20选择“生成原创、克制的合成音乐”，并要求最终使用OGG格式。
- 由AI辅助编写 tools/compose_menu_music.py，通过数学振荡器、包络和独立指定的音序合成。
- 未使用外部录音、采样、第三方乐曲或购买素材。这里说明生成来源，不伪称真人作曲或法律审定。
- 运行时资源：menu_theme.ogg，Ogg/Vorbis，立体声22050Hz，100BPM，16小节、38.4秒。
- NumPy与soundfile/libsndfile仅用于离线生成，不随游戏导出作为运行依赖。
- 循环接缝、解码时长、峰值、RMS和文件哈希见本轮自测日志。用户听感仍待实机认可。
